## Body

## What to build
Make owned-file commits atomic with respect to the repository index and competing helper processes.

## Blocked by
None — can start immediately.

## Acceptance Criteria

- The operation uses an interprocess repository lock or an equivalently serialized mechanism.
- Staging and validation occur in an isolated index or an equivalently rollback-safe transaction.
- A commit cannot include a path outside the normalized owned set, including when another process changes the real index concurrently.
- Every failure path preserves the original index and worktree state.
- Regression tests cover competing writers, pre-existing staged changes, partial staging failure, ignored files, pathspec magic, and platform path forms.

## Verification Plan

1. Run focused Git tests repeatedly and under the race detector.
2. Run process-level concurrency regression tests.
3. Run the full Go test suite on supported host platforms.
