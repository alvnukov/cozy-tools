## Acceptance Criteria

- Retained output contains the latest bytes rather than the earliest bytes after overflow.
- Interleaved stdout and stderr preserve observable order while callers can still identify the source stream.
- The total retained payload never exceeds one documented output budget.
- The output hash covers the complete redacted output even when retention truncates it.
- Callbacks, history, failure markers, and public result fields have documented and mutually consistent semantics.
- Regression tests cover large late failures, UTF-8 boundaries, interleaving, cancellation, and output from multiple writers.

## Verification Plan

1. Run focused command output and history tests under the race detector.
2. Run memory-bound and truncation regression tests.
3. Run the full Go test suite and gopls diagnostics.
