## Body

## What to build
Move host policy, protected paths, storage namespace, and remediation text behind immutable per-instance options. Shared packages must provide mechanisms and injection seams without mutable process-wide configuration or mcp-ai-helper-specific defaults and messages.

## Blocked by
CT-001 — Define the command-family trust model.

## Acceptance Criteria

- Independent runner or coordinator instances can use different config-path and policy providers without shared mutable globals.
- Shared package defaults and diagnostics contain no mcp-ai-helper-specific namespace, path, action, or remediation text.
- Host-specific denial policy and messages can be supplied through documented interfaces without reverse imports.
- Concurrent construction, reset, and execution are race-free and covered by regression tests.
- A compatibility path is documented for current consumers.

## Verification Plan

1. Run focused config, project, and command tests under the race detector.
2. Search exported shared-package text and defaults for host-specific coupling.
3. Run go vet, gopls diagnostics, and the full Go test suite.
